## 🌟 Overview

**NEXUS AI** pairs a high-precision CLI execution engine with a cinematic, liquid-glass web environment. Designed around the *Quiet Machine Cinema* aesthetic movement, the platform emphasizes:

- **Restrained Execution Rails**: Observe complex agent workflows step-by-step in real-time.
- **Cinematic Atmosphere**: Liquid-glass surfaces, Instrument Serif editorial typography, and deep navy canvas.
- **Local Autonomy**: Full terminal and system control under transparent user supervision.

---

## ⚡ Key Features

| Feature | Description |
| :--- | :--- |
| **CLI & Web Platform** | Direct integration between `NEXUS CLI` terminal tools and the `NEXUS AI` visual workspace. |
| **Real-time Tracing** | Step pips, signal nodes, and interactive execution logs for complete observability. |
| **Liquid-Glass UI** | Hardware-accelerated backdrop blur, subtle edge luminescence, and high contrast typography. |
| **Theme & Typography** | Powered by *Instrument Serif* and *Inter* with custom Tailwind v4 inline color systems. |
| **Full Stack Architecture** | Express backend paired with React 19 + Vite client engine. |

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Framer Motion, Radix UI
- **Build Tool**: Vite 7, PostCSS, `@tailwindcss/vite`
- **Backend**: Node.js, Express, `tsx`, `esbuild`
- **Package Manager**: `pnpm` v10

## 🚀 Quick Start

### Prerequisites
- Node.js `^20.0.0` or higher
- `pnpm` installed globally (`npm i -g pnpm`)

### 1. Clone Repository
```bash
git clone https://github.com/MERIL2026/nexux-ai.git
cd nexux-ai
```

### 2. Install Dependencies
```bash
pnpm install
```

### 3. Run Development Server
```bash
pnpm dev
```
Open your browser at `http://localhost:5173` (or the host port printed in the terminal).

### 4. Build for Production
```bash
pnpm build
```

## 🎨 Design System

NEXUS AI follows strict design guidelines:
